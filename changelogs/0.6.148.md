## Changes

- Replace the process-global binary resource map with an instance registry. Each legacy MCP server owns its registry, reads revalidate size and SHA-256, and server close clears its entries.
- Treat the modern MCP handler as stateless and unauthenticated: `mode=embedded` remains self-contained, `mode=both` explicitly falls back to embedded, `mode=link` fails with guidance, and modern `resources/list` exposes no cross-request registry.
- Snapshot the exact image bytes inspected by Node before Python conversion. The helper checks their SHA-256, rejects images above 40 million pixels, refuses pre-existing outputs, and atomically publishes by same-directory hard link without clobbering concurrent files.
- Make `project_reference_resolve` abstain when the latest Project Health observation is invalid or at least 24 hours old, using the same interval as the existing daily capture policy.
- Add a transport guide, refresh generated `TOOLS.md`, and correct the Librarian/Jev guide's outdated statement about the already-fixed 0.6.147 HTTP framing failure.
