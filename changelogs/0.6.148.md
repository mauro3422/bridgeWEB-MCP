## Changes

- Vendor the exact MSSR 0.2.102 release artifact (`vendor/mauroprime-mssr-0.2.102.tgz`, SHA-256 `a26e74b7dd8605a19062277615885bb63ba0d8e48cfb63c7d5f2640b1a24617b`) and advance the isolated Bridge candidate to 0.6.148.
- Add `mssr_librarian_evidence_pack` alongside the existing single-handle fetch. It accepts up to 16 exact handles plus the exact explicit Markdown sources they reference, and returns one unchanged, citation-bearing source range per paragraph.
- Before packing, Bridge requires the canonical managed project root, normalized unique source refs, unique handles, matching project owner and `project-metadata` privacy, and exact agreement between supplied sources and handle sources. It rereads only those sources; MSSR validates each current revision, range, and fingerprint.
- Classify the operation as read-only. It makes no Jev call, generates or compacts no prose, does not crawl, and cannot rewrite canonical files or establish truth.
- Keep search, Jev selection, one-handle exact fetch, relation review, and synthesis preview as distinct existing steps; the new batch pack is not a duplicate of single-handle fetch.
- Clarify that the pack validates caller-supplied current handles but does not authenticate their search/Jev selection history. Update the capability catalog from five to six tools and describe metadata-aware retrieval and host-level composition accurately.
- Update the Librarian/Jev integration guide, project context/memory/state, generated `TOOLS.md`, catalog regression expectations, and `tools/list` verification.
