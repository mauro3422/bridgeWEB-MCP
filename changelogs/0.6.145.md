## Changes

- Pin `@mauroprime/mssr` to the exact vendored 0.2.100 release-gate tarball. The source and vendor tarballs have SHA-256 `849b067d5f1578b3c32c73fc4e2bafcedaa8a5e01231ac1108fa92313a103d32`.
- Adopt MSSR's improved bounded excerpt-window selection, which favors the window covering the most distinct query terms and uses earliest-window tie-breaking while retaining the exact-fetch contract.
- Search exposes each exact range's UTF-16 code-unit size and fetchability. Jev selection omits ranges above the 20,000-unit fetch cap, reports offered/eligible/oversized counts on pre-provider exits, and makes no Jev call when every exact range is too large. It never truncates a handle or treats this as model abstention.
- Document that portable Librarian search accepts source-bound EvidenceAtoms/catalog records, while Bridge currently has no canonical producer/store wired to send them. Preserve the explicit source scope and reject caller assertions as a substitute for host-owned derivation.
- Clarify that intelligent grep loops, compaction, paragraph generation/assembly, and independent verification are host-composed stages; Jev is one bounded decision component and Bridge's preview remains deterministic source assembly.
