## Changes

- Bridge now discovers the package-owned MSSR skill tree through the portable manifest and `mssrFirstPartySkillsRoot()` API, so ChatGPT Web routing and loading do not depend on a duplicate `CODEX_HOME` mount.
- Added `mssr-first-party` to the skill catalog source schema and source-health report. Discovery reads only manifest-declared `SKILL.md` paths, verifies metadata against the reserved name, and constrains resolved files to the package root.
- `skill_load` auto mode now canonicalizes bundled first-party and external filesystem catalogs together; portable MSSR precedence selects the bundled reserved skill before a local/system/plugin homonym.
- Divergent external exposure of a reserved first-party name remains an explicit routing-audit error rather than being silently ignored or loaded.
- Added an isolated Bridge conformance regression for packaged discovery, auto-load precedence, and explicit external-shadow conflict reporting.
