## Changes

- Vendor the exact MSSR 0.2.115 release artifact and update the Bridge dependency pin.
- Add optional `dedupeContainedRanges` to `mssr_librarian_evidence_pack`; it defaults to `false`, preserving existing output behavior.
- Pass the option to MSSR. When enabled, MSSR validates every supplied handle before omitting only strict contained ranges with matching owner, source, and revision. The response includes full provenance for each omitted handle and the retained covering citation.
- Keep retained source text verbatim. Compaction does not infer that a parent range answers a child facet, call Jev, summarize evidence, or change canonical project files.
- Correct the observability liveness regression to wait for the intentionally backgrounded persisted-snapshot refresh to drain; while it is active, require that only the single expected snapshot request is pending. This removes a timing assumption without weakening the liveness or eventual-cleanup check.
