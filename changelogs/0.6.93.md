## Changes

- `narrated-media-review` now activates for direct audio/video listening and transcription requests as well as narrated visual reviews; pure transcription is a supported fast path instead of a negative intent.
- `media_review_ingest` is the canonical first transcription/review path while healthy. Generic Whisper/local ASR fallback is allowed only after observable failure or unavailability and must be reported before replanning.
- Meme/video interpretation requires both canonical transcript/audio evidence and at least one representative visual frame before explaining the result.
- `skill_route_plan` now surfaces Bridge-owned workflow-guide recommendations, while `skill_bootstrap` can also load the selected existing workflow guide so the canonical media procedure is available in the same bootstrap response.
- `workflow_guide_recommend` and Bridge server instructions explicitly direct callers to existing media pipelines before ad-hoc ASR fallbacks.
- Added `scripts/test-workflow-guide-routing.mjs` for audio/video routing and bootstrap integration, plus `scripts/verify-narrated-media-workflow.mjs` for activation/tool-policy contract checks.
- Added the workflow-guide routing regression to `npm run test:regressions` and exposed `npm run test:workflow-guide-routing`.
- `.bridge/mssr-context-inbox.json` is now ignored as local runtime delivery/receipt state; canonical project knowledge remains in the tracked PROJECT_* authorities and manifest.
