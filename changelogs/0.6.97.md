## Changes

- Packages `@mauroprime/mssr` 0.2.17 and consumes MSSR's canonical `.mssr/` project-home resolver instead of hardcoding Bridge-owned project-context paths.
- Moves Bridge's tracked `PROJECT_CONTEXT.md`, `PROJECT_MEMORY.md`, `PROJECT_STATE.md`, and `project-context.json` into `.mssr/`; `.bridge/` remains compatibility input for legacy MSSR data and remains available for unrelated Bridge-owned surfaces such as project workflow guides.
- Adds narrow `.mssr/.gitignore` hygiene across migrated modular repos so only `mssr-context-inbox.json` is ignored; PROJECT_* authorities and manifests remain versionable instead of hiding the entire project-control home.
- Project context assembly/audit/update now resolve `.mssr` first, report legacy migration debt, and write new MSSR-owned project knowledge only to `.mssr` while preserving optimistic-concurrency/rollback guarantees.
- Context Plane inherits MSSR 0.2.17 stale-pending replacement semantics and canonical `.mssr/mssr-context-inbox.json`; the live legacy inbox was copied forward through the portable resolver without deleting the legacy file.
- `mssr-trace-context` now accumulates bounded privacy-safe host metadata per open trace: relative path hints, tool names, material-write count, package/runtime/routing/skill-structure flags, Context Plane freshness issues, and user-correction count. It never retains edited source payloads as project-maintenance metadata.
- Bridge calls portable `evaluateMssrProjectKnowledgeMaintenance` instead of owning review heuristics. `WATCH` remains informational; `REVIEW`/`REQUIRED` emits a deduplicated Bridge notice, marks maintenance due through the portable lifecycle helper, and points the closing agent at `skill-maintenance-loop` plus only the named project/skill authorities.
- `project_change_consistency` also evaluates the same portable advisory against the observed Git change set, providing restart-safe/diff-based evidence when RAM trace metadata is incomplete.
- Updated AGENTS, README, tool descriptions, project context manifest, context-memory governance, and regressions for canonical `.mssr` storage and host-gated MSSR inheritance.
