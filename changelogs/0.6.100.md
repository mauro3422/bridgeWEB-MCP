## Changes

- Upgraded packaged `@mauroprime/mssr` to `0.2.20`.
- Exported/reused the common Bridge notice adapter instead of introducing another queue or producer-specific transport.
- Migrated Web lifecycle idle/missing-outcome attention to the portable transition evaluator. Idle can request REVIEW but never proves completion or synthesizes outcome; explicit progress/outcome resolves the idle attention state.
- Hardened idle reminder timing so a callback revalidates a newer progress lease before emitting and re-arms when the lease is still active.
- Migrated project-knowledge maintenance away from an artisanal notice key. Stable debt stays quiet; changed/escalated/deescalated/resolved transitions are now semantic, and resolution requires maintenance to close the current lifecycle revision.
- Replaced monotonic Context Plane freshness issue accumulation with current-state projection: `fresh -> OK`, unknown-only -> `WATCH`, stale/unavailable -> `REVIEW`, conflicting -> `ERROR`.
- A result without Context Plane freshness evidence does not erase the last observation; explicit fresh evidence resolves freshness attention. Unknown-only WATCH does not force durable maintenance.
- Added regressions for maintenance changed/resolved transitions, freshness open/stable/resolved/conflicting behavior, lifecycle stable idle suppression, progress resolution and lease revalidation.
- Updated roadmap, adapter documentation, README and PROJECT_* authorities. Remaining notice-plane migrations are provider/runtime/restart health, routing compliance, then selected reusable project watchers.
- Hardened workflow-guide/existing-skill ownership detection for routing and coverage diagnostics: skill/guide names cited as false-positive or false-negative examples are treated as diagnostic evidence rather than execution intent, preventing cross-domain ownership false positives without suppressing real specialist requests.
- Added negative coverage/recommendation regressions for diagnostic prompts plus positive preservation cases for Roblox placement, Roblox save/recovery and Figma design-to-code.
