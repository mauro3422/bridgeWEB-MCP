## Changes

- Port `asset_import_files` from the isolated 0.6.144 checkout onto the clean 0.6.161 / MSSR 0.2.110 source line; do not merge unrelated work from the old checkout.
- Declare the authorized top-level `files` parameter using `_meta["openai/fileParams"]` and register its write/persist lifecycle classification.
- Stream up to eight files (512 MiB each; 1 GiB per batch), enforce no-clobber destinations, compare expected sizes/hashes and detected MIME, and write an optional manifest without temporary download URLs.
- Reject non-HTTPS/non-standard ports, unapproved hostnames, private/special DNS answers, redirects, oversized streams, path-policy violations and failed batch commits.
- Add focused transfer and HTTP catalog regressions, generated tool documentation, and this release note.
