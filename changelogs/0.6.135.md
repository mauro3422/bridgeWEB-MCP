## Changes

- Adopt exact `@mauroprime/mssr 0.2.67` from `vendor/mauroprime-mssr-0.2.67.tgz`; source/vendor SHA-256 is `ec41a511aec958b545e646a278746bc282919d6c8b00f9b7f324537996ff0f3f`, and the installed critical project-maintenance bytes were verified equal to the MSSR build before host integration work.
- Replace lexical `skill-routing` path-substring classification with explicit semantic-owner paths. Documentation such as `docs/skill-routing/INCIDENTS.md` no longer creates routing/skill maintenance debt, while real routing owners such as `config/skill-routing/**` and source adapters still do.
- Add `src/document-freshness-host.ts` as the host observation adapter for MSSR's opt-in `.mssr/document-freshness.json`. Bridge supplies exact-path availability plus conservative Git/worktree revision ordering; MSSR remains the evaluator. A dirty/newer impact ref may make a document REVIEW-due, a dirty document makes ordering WATCH/unknown, and no freshness result proves semantic contradiction or authorizes rewriting canonical documentation.
- Compose Document Freshness into the existing Project Health snapshot and notice lifecycle. No second scheduler, queue, MCP tool, or semantic authority is introduced; absent registries remain a no-op, invalid registries become review evidence, and existing Project Health metadata remains content-free.
- Reuse `collectBridgeReleaseConsistencyObservations(...)` as the Bridge fact producer for C2e-D. Its bounded package/source/generated/installed/runtime observations are mapped through `buildMssrSemanticClaimSituation(...)` rather than re-read by another detector.
- `project-situation` now composes explicit semantic observations with receipt-derived Context Plane observations. Semantic claims can therefore be checked without an active context receipt; Bridge auto-produces them only for its own release/install/runtime contract unless another project defines an explicit structured producer.
- Preserve the existing ownership boundary: C2c/C2d still own consistency/recommendation semantics, Project Health/Situation remain host projections, and `bridgeNotices` remains the sole general notice transport.
