## Changes

- Add `metadataMode=project-context-librarian-sidecar` to the existing `mssr_librarian_search`; preserve the default lexical path and the 0.6.146 `project-context-single-section` path. No duplicate MCP tool is added.
- Read the librarian sidecar plus optional segment/reference manifests only at their canonical `.mssr/` paths, with bounded bytes, regular-file checks, UTF-8/JSON validation, project-control-directory containment and before/after revision/path checks.
- Call MSSR 0.2.101's portable projector using only explicit `sourceRefs`. It binds metadata to the current base manifest, exact heading path, current Markdown fingerprint, manifest source scope, and segment/reference suppression. Unselected Markdown, directives, stale or ambiguous headings, and indirectly managed modules cannot project selectors.
- Expose per-call manifest revisions, projection/omission counts, omission issues and exact entry-to-range bindings. Missing sidecar or changed metadata inputs produce lexical-only results; malformed or unsafe control files fail closed. Metadata stays advisory and non-persistent.
- Keep Jev selection as the existing separate call; search handles are passed explicitly and are revalidated against exact current source before any provider call.
- Update the Librarian integration guide, generated `TOOLS.md`, root compatibility changelog and project authorities. The active Bridge runtime is not restarted or deployed by this candidate.
