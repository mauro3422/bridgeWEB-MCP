## Changes

- Packaged `@mauroprime/mssr` `0.2.11` → `0.2.12` via `file:vendor/mauroprime-mssr-0.2.12.tgz`. The core exposes the durable `.bridge/mssr-context-inbox.json` plane with explicit delivery receipts.
- New `src/mssr-context-plane.ts` exposes `filterAcknowledgedContextMessages`: it reads the canonical inbox receipts and drops inline context messages whose id, kind, and evidence identity (revision included) match an already acknowledged receipt. Identical acknowledged evidence never redelivers; messages whose revision or content changed reappear and are deliverable again.
- Wired the filter into `prepareMssrContextPlane`, so both `skill_route_plan` and `skill_bootstrap` apply ack suppression before delegating to `loadProjectContextHost`.
- Boundary: the ack-tombstone is a delivery-surface suppression owned by the host adapter (inbox/piggyback delivery and local retention). Bridge never touches project semantics, never confirms delivery by selection, and never executes advisory actions or persistence proposals. Malformed inbox state still fails closed via the authoritative core loader.
- Added `scripts/test-mssr-context-plane.mjs` plus the `test:mssr-context-plane` script, registered in `test:regressions`. It verifies explicit durable manifest creation, redelivery before ack, disappearance of identical acknowledged evidence, reappearance only on revision change, unrelated-task non-delivery, and malformed-inbox fail-closed.
- `TOOLS.md` regenerated with 147 tools.
