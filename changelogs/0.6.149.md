## Changes

- Separate `BridgeCodeRoot` from `ProjectRoot` so a watchdog helper can launch code from one checkout while retaining the selected runtime, working directory, and operational state under the primary project root.
- Make `-DryRun` observational: do not stop a listener, consume a pending restart request, process a restart or automatic recovery, or write a restart acknowledgement.
- Add `test:http-watchdog-dry-run`, which verifies an external listener and restart request remain intact and no acknowledgement is written.
- Record the confirmed HTTP framing failure and unresolved process-exit cause in the incident ledger, and preserve the dry-run invariant in indexed operations memory.
