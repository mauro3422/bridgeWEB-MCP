## Changes

- Dashboard summary and snapshot projections skip the all-history event/trace total query, which the dashboard renderer does not consume. Full MCP `mssr_observatory_query` summaries retain their existing totals.
- Calculate active-epoch status totals with a bounded SQLite aggregate when the pending-write overlay is empty; retain the existing ID-deduplicating read-your-writes path whenever active events remain in the overlay.
- Filter active-epoch summary events and tool calls in SQLite before decoding rows, preserving the legacy/all-history scope.
- Align `SERVER_VERSION` in the HTTP runtime with the 0.6.188 package release.
- Correct the dashboard worker reuse test to ignore the request-accepted notice and wait for the actual response.
