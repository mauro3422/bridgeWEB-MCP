## Changes

- Replace the vendored MSSR 0.2.127 package with the exact 0.2.130 release-gate artifact, verified by its byte count, SHA-256, and package-lock integrity. Keep the prior 0.2.129 vendor artifact locally available for rollback.
- Pass request-scoped MCP progress delivery context through the Bridge tool registry, including the explicit `bridge_tool_action` delegation path.
- Before the watchdog request file becomes visible, `bridge_request_restart` attempts one `notifications/progress` signal when the caller supplied a progress token. The attempt is bounded to 300 ms; missing tokens, transport errors, and timeouts fall back to the existing maintenance notice in the tool response and never authorize or suppress the restart.
- Report whether the progress notification was sent to the transport, unavailable, failed, or timed out, while explicitly keeping client display/receipt unconfirmed.
- Expose `selectionMode=search-results|all-headings` for Jev selection, preserving legacy inference for non-empty handles/heading calls while requiring an explicit mode for an empty search pool. Empty results return without calling Jev.
