## Changes

- Add an append-only JSONL lifecycle record under the selected ProjectRoot logs directory. Events retain allow-listed process identity, UTC start/observation/stop-request times, uptime, exit code, termination confirmation, recovery trigger/action, correlation id, and replacement PID/start time.
- Keep raw command lines, process arguments, output, prompts, and secrets out of lifecycle records. Rotate a segment after 5 MiB to a unique archive name without deleting existing evidence.
- Include equivalent bounded process evidence in automatic tunnel restart acknowledgements. Preserve existing Bridge diagnostics while adding its lifecycle snapshot.
- Keep DryRun observational; it does not create lifecycle logs, stop children, consume a request, or write an acknowledgement.
- Add isolated Bridge and tunnel exit-code regressions alongside the existing dry-run regression.
- Record the confirmed post-reboot startup path and the limits of historical crash evidence.
