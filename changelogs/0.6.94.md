## Changes

- Added `windows_admin_cache_status`, a read-only inspector for Bridge-approved privileged cache profiles.
- Added `windows_admin_cache_cleanup`, a destructive tool that defaults to `dryRun=true`, accepts only a closed profile enum, and never accepts an arbitrary filesystem path or arbitrary elevated command.
- Added the first approved profile, `amd-dxc-cache`, resolving internally to `%LOCALAPPDATA%\AMD\DxcCache` and revalidating that exact boundary again inside the elevated helper.
- Apply mode crosses a visible Windows UAC boundary, runs the tracked profile-scoped PowerShell helper elevated, records deletion/failure evidence to a bounded JSON receipt, and post-verifies the target directory from the normal Bridge process.
- The generic `run_command` / terminal shell blacklist remains unchanged; privileged executables such as the ownership utility stay blocked there.
- The release tree also packages MSSR core `0.2.16`; Bridge bootstrap now consumes the portable `resolveMssrHostSkillSelection` and `planSkillContexts` APIs instead of duplicating that selection/planning logic locally.
- Added daily structural skill-health snapshots in `data/skill-health.json`: advisory-only, no skill content stored, no auto-editing, 24-hour capture cadence with hourly due checks and bounded 90-snapshot retention.
- Added `GET /api/mssr/skill-health` plus the dashboard card `Salud estructural de skills` so WATCH/REVIEW signals, manifest coverage, recipe/reference counts, size and growth deltas can be reviewed without changing routing automatically.
- Added `scripts/test-skill-health.mjs` and included it in the full regression suite.
- Skill discovery now carries exact `SKILL.md` SHA-256 content hashes so a byte-identical MSSR package/runtime copy is informational first-party alias evidence, while a genuinely divergent reserved-name shadow still blocks the audit.
- Added `scripts/test-windows-admin-tools.mjs` to protect profile validation, dry-run behavior, risk classification, target resolution, and the continued generic-shell block.
- Recovered the protected AMD DXC cache through the new path during validation: the remaining 12 `.parc` files (8,815,806,674 bytes) were removed and the directory was verified empty.
