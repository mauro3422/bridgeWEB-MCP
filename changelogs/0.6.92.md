# 0.6.92 - 2026-08-14

## Contract

- Summary: make the native Godot scene tools safe for the shared multi-editor provider. Bridge now enumerates every connected editor, accepts explicit `projectPath`, `projectId`, or `editorInstanceId` targets for scene open/create, forwards the selected target through every provider read/write/readback call, and refuses ambiguous scene mutations when multiple editors are connected without a target.
- Areas: Godot, tools, multi-editor targeting, editor safety, Atlas integration

- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Changes

- `godot_mcp_instance_list` consumes provider 0.3.7's full `instances` array instead of presenting only the default editor.
- `godot_scene_open` and `godot_scene_create` expose optional exact editor selectors: `projectPath`, `projectId`, and `editorInstanceId`.
- Target identity is forwarded through provider status, scene read, create/open, and active-scene verification so evidence cannot silently come from another connected project.
- When multiple editors are connected and no target is supplied, dedicated mutating scene operations fail closed instead of using the provider's default/first editor.
- Focused fake-provider regression coverage now exercises two connected editors, instance enumeration, ambiguous mutation rejection, and explicit targeted scene operations.
- This release composes with MauroPrime Godot MCP provider 0.3.7 and GodotAtlas's provider-owned editor-only host; it does not add UI automation or duplicate provider ownership.
