## Changes

- Added read-only `project_context_audit` to classify workspace repositories as modular, legacy, invalid, empty-bridge, not-initialized, or unmanaged.
- Added read-only `project_change_consistency` to compare Git changes, package version, version changelog, changelog index, and PROJECT_* impact declarations before persistence; `scope=staged` isolates the final commit gate from unrelated parallel work in a shared worktree.
- `project_context_load` now warns when `.bridge` exists without a modular manifest and distinguishes legacy authorities from an empty authority directory.
- MSSR structured intent can select `changelogs/INDEX.md` plus the current version changelog for debugging/recovery/history work without loading the legacy archive.
- Project knowledge remains explicit: audit/load never invent or auto-write durable memory.
- HTTP smoke verification no longer hardcodes a historical tool count; it now requires the audit endpoint to return its own complete registered catalog, preventing release-count drift such as 144 -> 146 from producing false failures.

## Verification

- Portable MSSR change-history parser/evaluator has focused tests.
- Bridge project-context and change-consistency regressions cover stale changelog blocking and verified PROJECT_STATE updates.
