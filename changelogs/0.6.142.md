## Changes

- Added `mssr_librarian_search`, `mssr_librarian_fetch`, `mssr_semantic_evidence_relation_review`, and `mssr_semantic_evidence_synthesis_preview` by reusing the public MSSR 0.2.93 library APIs. P6 had no existing Bridge Librarian/Jev handlers; QuietDesk's `structured_jev` value was telemetry only.
- Bridge reads only explicit project-relative Markdown paths under a Git repository with canonical `.mssr/project-context.json`. It rejects traversal, symlink escapes, internal symlink/junction aliases to excluded trees, non-Markdown sources, `data/`, `logs/`, `.git/`, `.bridge/`, `node_modules/`, `.mssr/runtime/`, sensitive-looking path segments, and colon-containing paths including Windows Alternate Data Streams. Per-file, batch-byte, and file-count limits are enforced before invoking MSSR.
- Fetch, relation review, and synthesis preview reread the exact current host source. Relation review and preview ignore caller-supplied evidence text and validate the fetched revision, range, and fingerprint through MSSR. Search handles remain candidates and owner/privacy provenance stays host-asserted.
- Jev relation review reads its credential from Windows Credential Manager only when called. The SDK endpoint is pinned to `https://api.typesafe.ai`, so inherited `TYPESAFE_BASE_URL` cannot redirect the credential. It sends no key in tool arguments or telemetry, disables SDK logging, clears returned byte buffers, and suppresses provider response bodies/errors. The tool is classified as an external side effect because it makes a provider request and may consume account usage.
- Synthesis remains a reversible preview with `canonicalRewriteAllowed=false` and `applyAllowed=false`; Bridge adds no file-writing path.
- Adopted MSSR `0.2.93` from the locally built tarball. The tarball copied to `vendor/mauroprime-mssr-0.2.93.tgz` has SHA-256 `738183d3850760c99b2d6c10b88f0cc285dff2201c94f456b0914a160d83ae43`, matching the source artifact.
- On 2026-09-30, Jev reviewed a sanitized aggregate of ignored Bridge runtime state (10,675 files, about 1.69 GB). It supported preservation/classification, contradicted deletion, and abstained on whether the aggregate inventory justified deletion. No paths or contents were sent and no runtime file was deleted. This review does not replace deterministic owner/activity/retention evidence.
- Added a focused Bridge regression covering explicit search/fetch, canonical-target exclusions through junctions, Windows Alternate Data Stream rejection, current-source rereads before Jev and preview, no-write behavior, provider response validation, credential-buffer clearing, and endpoint pinning under a malicious inherited SDK URL. `src/mssr-observatory.ts` now narrows the versioned telemetry union explicitly before consuming a checkpoint, required by the 0.2.93 declaration.
- Corrected `test-bridge-regressions.ps1` to default to the checkout containing the script instead of hard-coding `D:\Dev\bridge-mcp`, so isolated full-suite runs validate the active worktree.
- Updated the exact-package MSSR R4 adoption regression to assert version `0.2.93` and the vendored tarball's current SHA-256, retaining byte-parity protection across the package bump.
