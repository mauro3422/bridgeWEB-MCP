## Changes

- Added `windows_admin_storage_audit`, a read-only tool with an empty input schema: callers cannot supply paths, commands, profiles, or other privileged parameters.
- Added `scripts/windows-admin-storage-audit.ps1`, invoked only through the existing visible UAC launcher. It reports C: drive usage, pagefile allocation, VSS shadow-storage state, Windows Reserved Storage state and storage-reserve quotas, Windows RE configuration, and bounded protected-directory summaries.
- Kept `run_command` and terminal privilege policy unchanged; administrative executables remain unavailable as a generic shell escape hatch.
- Extended Windows-admin regression coverage and the global tool-count contract from 151 to 152 tools.
- Used the new audit during the C: investigation: VSS reports 0 bytes used and no shadows; Windows RE is on the dedicated recovery partition; Windows Reserved Storage is enabled and `fsutil storagereserve query C:` reports 6,711 MB of guaranteed reserve across active reserve IDs.
