## Changes

- Centralized Bridge and external-host classification of `traced`, `unrouted`, `bootstrap`, and `exempt` calls. Diagnostic tools and MSSR route/bootstrap/checkpoint hooks remain observable but are excluded from the substantive-call denominator.
- Added privacy-safe chain coverage to Bridge metric surfaces and agent profiles: substantive, routed, unrouted, and route/bootstrap/hook-missing chain counts. Chain keys use only already-bounded trace, caller, session, task, workflow, and project identifiers.
- Updated the dashboard and metrics tool description to show chain coverage and exempt call counts rather than presenting diagnostic activity as missing trace coverage.
- Host-gated optional roots with no supplied decision now remain `pendingCandidates` with `decisionState: absent`; they no longer emit synthetic `skipped/not-evaluated` telemetry. Explicit host `accepted`/`skipped` records and reason codes are preserved unchanged. Context-budget skips remain context-planner evidence, not semantic host decisions.
- Added a regression for substantive denominator, diagnostic exemption, route/bootstrap/hook evidence, and explicit unrouted-chain detection.
