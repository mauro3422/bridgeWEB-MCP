## Changes

- Resolve the allowlisted download hostname once, reject empty or mixed public/private/special answers, and pass only the validated address set to the HTTP(S) connection lookup.
- Keep the source hostname on the request so the `Host` header, TLS SNI and certificate verification continue to use the authorized origin. TLS verification remains enabled; redirects remain rejected.
- Request identity transfer encoding and reject a response with a non-identity `Content-Encoding`, so the stored bytes are not silently transformed.
- Add a reserved `.invalid` host regression pinned to a local test listener. It proves the request uses the validated address without an independent DNS lookup and preserves the original Host header.
- Keep the existing planned-restart response notice unchanged. It advises the requesting chat to wait for Bridge readiness before retrying. Bridge has no push channel to broadcast that response to unrelated web chats.
