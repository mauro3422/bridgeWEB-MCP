## Changes

- Derive catalog records and EvidenceAtoms per call from owner-declared `domains`, `actions`, `artifacts`, `needs`, and `signals` in the canonical `.mssr/project-context.json`.
- Project selectors only for `context`, `memory`, or `state` modules with one explicitly declared, uniquely present Markdown heading in an explicitly selected source. Multi-section, whole-file, directive, missing, ambiguous, unselected, and selector-free modules remain untagged.
- Bind every projected selector to the current source revision, exact section range, payload fingerprint, canonical owner, and per-call freshness observation. Expose manifest revision, skip counts, and exact selector bindings in search results; metadata stays advisory and cannot rewrite canonical sources.
- Keep metadata matching opt-in and lexical search unchanged by default. If the manifest changes during the read or atom/record limits are exceeded, discard the derived metadata batch and return lexical-only results with an explicit status.
- Keep search and Jev selection as separate steps: callers pass exact metadata-search handles to Jev selection, whose existing owner/source/revision/range/fingerprint revalidation remains in force. No duplicate tool, persistent index, telemetry store, or prose-generation claim is added.
