# 0.6.114 — 2026-08-22

- Summary: Make MSSR skill context delivery bounded and resumable so ChatGPT Web cannot silently lose accepted procedural context when a bootstrap response exceeds the host envelope.
- Areas: MSSR package adoption, skill bootstrap, continuation cursor, ChatGPT Web, observability, dashboard, privacy, regression coverage
- PROJECT_CONTEXT: updated
- PROJECT_MEMORY: updated
- PROJECT_STATE: updated

## Changes

- Adopts exact packaged MSSR `0.2.53` from `vendor/mauroprime-mssr-0.2.53.tgz` (608830 bytes, SHA-256 `1805ac508f7a1828247d63df38f61b0d2bbc8c583d5158acfa2cca28f20c8571`). Portable MSSR owns deterministic page order, `required|accepted` obligations, cursor integrity/freshness, indivisible-unit blocking and core/module duplicate avoidance. The intermediate 0.2.52 artifact remains immutable but is not the final Bridge dependency.
- `skill_bootstrap` compact responses now distinguish selected procedural budget from total serialized envelope, report exact `responseChars`, and return `status`, `mustContinue`, bounded `remaining`, opaque `cursor` and an exact `nextAction` whenever another page is required.
- Adds read-only `skill_context_next`. Bridge retains only sanitized ephemeral continuation metadata in RAM for 30 minutes, fingerprints rather than persists the cursor, reconstructs live skill sources on every page, rejects tampered/stale/consumed/expired cursors, and requires a fresh bootstrap after restart.
- Preserves optional-root acceptance as `accepted`; accepted skills remain eligible and pageable but are not relabeled as required workflow obligations. Required roots and only their dependency closure remain `required`.
- Notices are recovery/control evidence for an abandoned chain, never a substitute transport for missing procedural context. Server instructions require continuing until `status=complete` before dependent work.
- Adds one aggregate `context_assembly` observability event per bootstrap/continuation page. It records only bounded counts and sizes—requested/delivered/response/envelope chars, remaining units and chain state—and globally strips cursor-named fields. Dashboard context traces show budget pressure and continuation progress without content or cursor values.
- Runtime catalog grows from 160 to 161 source tools. Generated `TOOLS.md` includes the new continuation schema.
