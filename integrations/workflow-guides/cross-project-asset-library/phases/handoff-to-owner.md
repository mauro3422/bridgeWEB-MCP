# handoff-to-owner

## Goal

Continue actual asset work in the authoritative project when the library reveals a pending action.

## Instructions

Open/load the owning project's context and its project-specific asset workflow. Do not carry a library-owned MSSR trace across a project-ownership boundary as if ownership changed; create/replan under the new project owner while preserving bounded handoff context. Use the library as evidence/navigation, not as the execution owner of Blender/Godot/Roblox source edits.
