# refresh-or-onboard-provider

## Goal

Rebuild existing providers or add a new provider adapter without copying canonical project sources into the library.

## Instructions

For refresh, run the library build/verify path and copy only allowed presentation derivatives. For onboarding, edit only MauroAssetLibrary adapter/config/schema/test files; provider repositories remain read-only. Namespace identity by projectId/assetTrackId/runId. Preserve source paths, declared evidence, measured evidence and provider navigation.
