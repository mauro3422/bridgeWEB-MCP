# evaluate-gates-and-drift

## Goal

Represent current usability truthfully when validated snapshots, working sources, approvals or permissions differ.

## Instructions

Keep validated snapshot evidence separate from the current working source. If measured working source differs from declared validated evidence, mark source drift and block current-source validity rather than rewriting the expected hash. Technical PASS never implies human approval. Preserve export/runtime/Godot/Roblox authorization exactly as durable provider evidence states.
