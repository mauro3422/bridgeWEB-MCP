# interpret-dashboard

## Goal

Use the capture dashboard and album according to the comparison task rather than treating all images as one flat sequence.

## Instructions

Identify the primary comparison axis from the workflow. For temporal or growth evidence, organize first by stage/age/state and second by camera position. Keep camera names and ordering consistent within each stage. Use Panorama as a summary across stages, not as a duplicate gallery. When useful, define a secondary comparison mode that fixes one camera and traverses stages. Preserve capture/version metadata and avoid silently mixing separate runs.
