# act-on-board

## Goal

Add text, diagrams, SVG, or existing images without erasing or obscuring the user's context.

## Instructions

Use whiteboard_add_text for structured prose, whiteboard_add_diagram for safe shapes/arrows/paths, whiteboard_add_svg only for sanitized custom SVG, and whiteboard_insert_image only for an existing local PNG/JPEG/WebP. Place additions in free space or beside the referenced area; do not cover user strokes or important images. State the intended placement relative to visible landmarks when coordinates are uncertain. Do not claim the object exists until the tool confirms it.
