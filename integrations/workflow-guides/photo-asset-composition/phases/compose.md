# compose

## Goal

Montar assets en escena fijada sin drift.

## Instructions

Preferir composición determinista por capas con máscaras, coordenadas, escala y profundidad; sombras/oclusiones coherentes. Si sintetiza con generador, usar base como entrada explícita, preservar perspectiva, no crear decorado. Guardar archivos fuente y cada revisión con versiones.
