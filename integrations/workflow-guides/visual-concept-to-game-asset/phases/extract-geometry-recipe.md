# extract-geometry-recipe

## Goal

Translate observed reference characteristics into a measurable, reproducible construction recipe.

## Instructions

Use the saved image-observation record as the source of visual intent. Extract normalized bounds, relative proportions, axes, primary/secondary masses, profiles by height, inclinations, repetitions, anchors, materials, VFX and growth curves.

Every recipe element must cite the visible characteristic it implements. Record:

- observation id or reference view;
- intended characteristic;
- construction primitive or mesh strategy;
- normalized size, position, rotation and parent relationship;
- allowed simplification;
- confidence level;
- unresolved visual risk.

Separate observed geometry from invented completion. A hidden underside, back face or internal topology may be hypothesized for production, but must not be presented as something seen in the reference.

The recipe must include explicit acceptance checks for silhouette, mass hierarchy, topology/branching, material family, growth/state behavior and game-scale readability.
