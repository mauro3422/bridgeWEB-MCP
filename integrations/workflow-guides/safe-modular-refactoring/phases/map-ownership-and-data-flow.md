# map-ownership-and-data-flow

## Goal

Entender responsabilidades, dependencias, estado y contratos antes de extraer código.

## Instructions

Construir inventario de funciones, llamadas, globals, eventos, DOM ids, rutas y datos de entrada/salida. Clasificar pure helpers, selectors, renderers, state, controllers, adapters y bootstrap. Marcar código muerto por referencias reales, no por intuición.
