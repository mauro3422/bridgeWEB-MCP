# compare-and-critique

## Goal

Create machine-readable metrics plus human visual judgment.

## Instructions

Generate overlays and contour diagnostics when a reference exists. Review readability, silhouette, hierarchy, materials, scale, state clarity, clipping, camera consistency, and animation extremes.

Use `image_file_attach` to inspect the original master reference and accepted master captures before writing the human verdict. Contact sheets and overlays are supplementary; do not replace masters with thumbnails, copied Base64, tunnels or temporary web delivery.
