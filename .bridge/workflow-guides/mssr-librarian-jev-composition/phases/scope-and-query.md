# scope-and-query

## Goal

Define a question and an explicit, authorized Markdown corpus before retrieval.

## Instructions

Resolve the canonical project root and select only relevant project-relative .md sourceRefs. Decompose the user task into a small set of answerable primary and follow-up queries; keep language and named concepts from the source corpus. Do not crawl directories or include .mssr/runtime, data, logs, secrets, credentials or unrelated projects. Record the needed answer dimensions and what evidence would count as coverage.
